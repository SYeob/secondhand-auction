# Pa-Bi Postman 핵심 입찰 실행 기록

상태: NOT RUN (실행 후 복사하여 작성)

| 항목 | 값 |
|---|---|
| 실행 일시 및 시간대 | 미실행 |
| 테스트 환경 / 서버 버전 | 미확인 |
| Collection 브랜치 / 커밋 | 실행 시 기록 |
| Postman 버전 | 실행 시 기록 |
| 실행자 | 실행 시 기록 |
| 실행 방식 | Collection 전체, 00 준비 포함, Iterations 1 |
| 테스트 계정 구분 | 판매자 / 입찰자 A / 입찰자 B (비밀번호·토큰 기록 금지) |

| TC ID | 입력 조건 | 결과 | 실패 단계 / 증적 / 관련 이슈 | 정리 결과 |
|---|---|---|---|---|
| TC-BID-001 | 15,000원 | NOT RUN | | 미실행 |
| TC-BID-002 | 현재가와 같음: 10,000원 | NOT RUN | | 미실행 |
| TC-BID-002 | 현재가보다 낮음: 9,000원 | NOT RUN | | 미실행 |
| TC-BID-003 | A 15,000원 → B 20,000원 | NOT RUN | | 미실행 |
| TC-CLOSE-001 | 종료 상태, 15,000원 | NOT RUN | | 미실행 |
| TC-BID-004 | 익명 | NOT RUN | | 미실행 |
| TC-BID-005 | 잘못된 토큰 | NOT RUN | | 미실행 |
| TC-BID-006 | A 토큰 / B 사용자 ID | NOT RUN | | 미실행 |
| TC-BID-007 | 금액 누락 | NOT RUN | | 미실행 |

PASS는 모든 기대 결과와 정리까지 확인했을 때 기록합니다. 준비 실패는 BLOCKED, 제품 규칙 위반은 FAIL, 건너뛰거나 일부 요청만 실행했다면 NOT RUN 또는 BLOCKED입니다. TC-BID-002 전체 PASS에는 두 입력 조건의 PASS가 필요합니다.

## 결함 및 잔여 위험

실행 후 작성. 로그인 응답, 토큰, 비밀번호는 첨부하지 않습니다. 증적에는 TC ID·입력 조건·상태 코드·민감값을 제거한 기대/실제 결과·이슈 링크를 남깁니다.
